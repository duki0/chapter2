* 깃 지역 저장소로 설정하는 방법 git init --> .git 폴더가 생성됨 * 깃 지역 저장소로 설정한 것을 취소하는 방법 rm -rf .git --> 명령어 실행 대신 .git 폴더를 삭제해도 됨 * 깃 지역 저장소의 사용자 정보를 등록하는 방법(깃허브 계정과 동일해야 함) git config user.name "사용자 이름" git config user.email "이메일 주소" --> .git\config 에 저장됨 * 깃 원격 저장소 설정 방법 깃허브에서 New repository 생성 git remote add origin {원격 저장소 주소} --> .git/config 에 저장됨 * 깃으로 관리할 필요가 없는 파일 설정 방법 .gitignore 파일을 최상위 경로에 생성함 * 깃은 프로젝트의 작업을 효율적으로 처리하는 작업트리라는 개념을 사용함 * 작업트리란 것이 추적(관리)하는 파일과 추적하지 않는 파일을 구분하고, 파일들의 상태를 구분 짓는 영역임 * 깃 작업트리는 "작업 디렉토리 -(add)-> 스테이징 영역 -(commit)-> 지역 저장소" 영역이 존재함 * 깃에서 관리하는 파일은 Untracked(추적하지 않은)와 Tracked(추적하는) 상태로 나뉨 * 새로 생성된 파일은 Untracked 상태 * 현재 파일 상태 확인 방법 git status * 커밋에 포함될 파일로 등록 방법 git add 파일명 또는 폴더명 --> 파일이 Tracked 상태가 됨 * 스테이징 영역에 추가된 파일은 수정 여부에 따라 Unmodified(수정되지 않은) 상태와 Modified(수정된) 상태로 분류됨 * 스테이징 영역에 있는 파일을 커밋 하는 방법 git commit (엔터 --> i 입력 --> 커밋 문구 입력 --> esc키 --> :wq 입력 --> 엔터) * 현재 작업하는 브랜치의 커밋 로그 확인 방법 git log git log -p --> 파일 단위에서 변경 내용을 보여줌
